# Goal Tracker

Приложение для управления целями, задачами и привычками с Supabase/PostgreSQL бэкендом.

## 🚀 Запуск приложения

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка Supabase

1. Создайте проект на [Supabase](https://supabase.com)
2. Получите URL и API ключи из настроек проекта
3. Создайте файл `.env.local` в корне проекта:

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=your-anon-key
```

### 3. Запуск приложения
```bash
npm run dev
```

Приложение будет доступно по адресу: http://localhost:5173

## 🏗️ Архитектура

### Фронтенд
- **React 18** с TypeScript
- **Vite** для сборки
- **Tailwind CSS** для стилизации
- **Zustand** для управления состоянием
- **React Hook Form + Zod** для валидации форм
- **React Router** для навигации
- **Recharts** для графиков

### Бэкенд
- **Supabase** (PostgreSQL) как основная база данных
- **Supabase Client** для работы с БД
- **Row Level Security** для защиты данных
- **Аутентификация** через Supabase Auth

### Структура проекта
```
src/
├── components/          # UI компоненты
├── components/forms/     # Формы
├── hooks/              # React хуки
├── lib/                # Утилиты и MongoDB
├── pages/              # Страницы приложения
├── services/           # Сервисы MongoDB
├── stores/             # Zustand сторы
├── types/              # TypeScript типы
└── main.tsx           # Точка входа
```

## 📊 Функционал

### 🎯 Цели
- Создание, редактирование, удаление
- Этапы и задачи
- Прогресс по задачам или метрикам
- Категории и приоритеты
- Дедлайны (4 типа)

### 📝 Задачи
- Подзадачи
- Приоритеты и сложность
- Вес вклада в прогресс
- Периодические задачи

### 📊 Метрики (Привычки/Счётчики)
- Два типа: привычки и счётчики
- Запись прогресса с шагом или вручную
- Аналитика с графиками
- Серии и рекорды

### 📅 Календарь
- Месячный вид
- Фильтрация по типам сущностей
- Отображение задач, целей, метрик

### 📈 Аналитика
- Статистика по целям
- Графики прогресса
- Тепловые карты активности
